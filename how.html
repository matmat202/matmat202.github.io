How these sites were made

Every site here was built by Claude Code running unattended in a workspace I set up on my own machine. I wrote the rules it works under; it picks most of its own projects, builds them, tests them and keeps a journal. These are the rules, and what came out.

The rules

A file every session reads before it does anything. These six carry the most weight.

  1. Read the brief first, write the handoff last.

    Sessions do not remember each other. Every one starts by printing the current state and ends by writing the single next concrete action, worded so a session with no context can do it. A project with no next action is how work dies.

  2. No review gate, but every promotion is announced.

    An idea that scores high enough on a written rubric is started at once, without asking. The announcement is the safeguard: the owner kills early rather than approving late.

  3. Writes stay inside the sandbox, and a hook enforces it.

    Agents run without permission prompts, so a pre-tool hook denies any file write outside the workspace and the agent's memory. Installs are project-local, disk has a 20 GB budget, and nothing is deleted that can be moved to trash instead.

  4. Re-publishing is pre-approved; publishing anything new is not.

    An agent may push an update to a site that already exists, and that site's own test gates are the approval, so no gate may be weakened to ship. A new repository, post or message needs an explicit yes for that one act.

  5. Parallel sessions claim work before touching it.

    Several agents run at once. A claim on a project goes stale when its holder's process dies or it goes 90 minutes without a refresh, and a stolen claim is reported.

  6. Done means run, not written.

    A project is done when it works and has been run. Failures and dead ends go in the journal with the same weight as wins, and no benchmark number is claimed that was not measured on this machine.

Where the ideas went

With nothing assigned, a session thinks up candidates, checks each against everything already built here and on the web, and scores the survivors. At least 4 in 10 die at the check, because the thing already exists.

  • 5,879 ideas written down and checked
  • 2,944 closed because they already existed, here or elsewhere
  • 361 promoted to a project

Of all 457 projects, its own and mine, 362 are finished and have been run, and 57 were abandoned — 56 of those with the reason written down, because a dead end recorded is worth more than one left to stall.

What I ask of it

29 of the projects were mine to assign; the rest it proposed itself. Mine always come first, and it drops its own work the moment I ask for something. Everything else — 7,125 journal entries since 2026-10-17 — it does on its own.
